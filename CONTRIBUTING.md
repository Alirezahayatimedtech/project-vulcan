# Contributing

VULCAN is currently an early research prototype.

## Working rules

- No real patient data in this repository.
- No credentials, API keys or hospital endpoints in commits.
- New clinical workflows must define intended use, excluded use and approval points.
- High-risk autonomous clinical actions are out of scope for the prototype.
- Prefer declarative workflow specifications over arbitrary generated code.
- Every new generator should have deterministic tests.
- Every new connector must document permissions, provenance and audit behavior.
