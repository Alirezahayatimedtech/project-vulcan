# Project Vulcan

**Healthcare systems, forged on demand.**

Project Vulcan is an early-stage exploration of an AI-native healthcare software platform that turns a clinical or operational need into a working software system.

Instead of asking users to manually build workflows, agents, integrations, interfaces, and decision-support logic, Vulcan aims to let them describe the capability they need and generate the system around that intent.

## Core idea

```text
Healthcare need
    ↓
Intent understanding
    ↓
System specification
    ↓
Workflow + agents + integrations + interface
    ↓
Safety validation
    ↓
Deployable healthcare software
```

## Long-term vision

**Need in → healthcare system out.**

Vulcan is intended to explore the transition from fixed healthcare software toward healthcare software generated and operated on demand.

## Current stage

Concept definition, literature mapping, architecture design, and first proof-of-concept planning.

> **Working codename:** Project Vulcan. The final company/product name has not been decided.
