# Roadmap

## Phase 0 — Define

- map related work and competitors
- define the healthcare intent-to-system architecture
- select one narrow clinical workflow for the first proof of concept
- define safety and evaluation criteria

## Phase 1 — Prototype

Build a minimal pipeline:

```text
Natural-language need
→ structured specification
→ generated workflow
→ simulated execution
→ validation report
```

## Phase 2 — First healthcare application

Generate one end-to-end application from the same core platform and test it with clinicians.

## Phase 3 — Generalize

Demonstrate that the same architecture can generate multiple healthcare applications without rebuilding the platform from scratch.

## North-star milestone

**One platform → multiple healthcare systems generated from intent.**
